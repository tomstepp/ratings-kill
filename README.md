# Ratings Kill

A Duke Nukem (1991)-style run-and-gun platformer. Rex Halloway, a former mattress-commercial star, fights his way down
the Tower Below while the Galactic Content Syndicate broadcasts it live. Stylish play fills the ratings meter, a full
meter buys sponsor drops, and a bored audience makes the Showrunner "spice things up".

Design doc: [docs/GAME_DESIGN.txt](docs/GAME_DESIGN.txt).

## Status

Phases 1–3 of the build plan:

- **Feel**: momentum running, variable jump height, coyote time, jump buffering, stacking blaster shots
- **Vertical slice**: two Floor 1 levels (*Platform Zero*, *Rush Hour Ruins*) with keycards, locked doors, levers and
  bridges, electrified rails, crates, TV blocks, secrets behind fake walls, 8 health pips, firepower upgrades
- **Show layer**: ratings meter, sponsor drops, boredom penalties (rat deliveries, falling stage lights), Showrunner and
  B0-0M dialogue with voice blips, 14 achievements, the break-room shop, Boom's flash-stun, Rex's quips with
  QUIP KILL bonuses
- Title screen, pause menu, end card

Next up (Phase 4): the remaining Floor 1 levels, The Mascot boss, saving between levels, Tanya Voss cameos.

## Running it

Requires [Godot 4.7](https://godotengine.org) (free). Installed here via `brew install --cask godot`.

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path .
```

Or open the folder in the Godot editor and press Play.

Dev shortcuts (arguments after `--`):

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path . -- --level=1        # jump to a level (0-based)
/Applications/Godot.app/Contents/MacOS/Godot --path . -- --room=test_room  # movement sandbox
/Applications/Godot.app/Contents/MacOS/Godot --path . -- --screen=break   # break room with $2500
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . -- --test # automated mechanics checks
```

## Builds

Export templates for Godot 4.7.2 are needed once (Editor → Manage Export Templates, or the official `.tpz`).

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --export-release "Web" build/web/index.html
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --export-release "macOS" build/mac/RatingsKill.zip
node tools/serve_web.mjs 8060   # then open http://localhost:8060
```

The web build is single-threaded, so it runs on any static host (GitHub Pages, itch.io) without special headers.

## How it's made

Everything is original and generated by code, so there's nothing to license:

- `tools/gen_art.py` draws every sprite, tile and the pixel font from one fixed 16-color palette
- `tools/gen_audio.py` synthesizes the sound effects and chiptune loops
- Levels are ASCII maps in `levels/` (see [levels/README.md](levels/README.md)); `tools/check_levels.py` proves each one
  can be finished

After changing art or audio, re-run the generator and then `Godot --headless --path . --import`.

```
scripts/
  autoload/   art, sfx, game_state, ratings, showrunner
  player/     rex (movement, quips), boom (drone), bolt
  enemies/    enemy base, rat_drone, spark_bot, enemy_bolt
  pickups/    pickup, crate, tv_block, sponsor_crate
  world/      level (map loader + show events), door, exit_door, lever, rail, trigger_zone, stage_light
  ui/         hud, title_screen, break_room, end_card
  dev/        dev_tools (screenshots, input bot), playtest (automated checks)
```
